# Flight Delay & Price Intelligence Platform ✈️

## Project Overview

This project analyzes airline delays, airport performance, and flight ticket price trends using Python, SQL, and Streamlit.

---

## Features

- Flight delay analysis
- Airline performance comparison
- Airport traffic insights
- Interactive dashboards
- Data visualization
- Delay prediction (future)

---

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Streamlit
- Git & GitHub
